# الجرس المدرسي الذكي V3 — Kotlin / Jetpack Compose
تطوير أ. محمد حيدره | 785068859

## ما هو موجود فعليًا
- لوحة عربية وتصميم أزرق/ذهبي.
- عد تنازلي مباشر بالثانية إلى أقرب موعد مستقبلي وفق أيام التكرار.
- إضافة وتعديل وحذف الأحداث مع الصف والشعبة والمادة.
- حفظ محلي للإعدادات والجدول.
- تصدير واستيراد ملف JSON بواسطة منتقي ملفات أندرويد.
- مشاركة نسخة JSON كنص عبر تطبيقات المشاركة.
- الاتصال بالمطور وفتح رابط واتساب (بافتراض رمز الدولة +967).

## ما ليس منفذًا بعد
هذه نسخة مصدرية للوحة الجدول وليست نظام رنين خلفي جاهزًا: لا تحتوي على مشغل أصوات أو جدولة AlarmManager أو خدمة foreground أو نافذة overlay أو مستقبل boot. مفتاح التفعيل حاليًا إعداد محفوظ فقط. لا تعتمد عليها كجرس المدرسة حتى استكمال هذه المكونات واختبارها على هاتف حقيقي.

## التشغيل
افتح المجلد كمشروع Android Gradle في Android Studio أو بيئة تدعم Gradle وJetpack Compose. يحتاج تنزيل التبعيات من الإنترنت وAndroid SDK 35 وJDK 17. لم يُبنَ APK أو يُجرَ اختبار ترجمة داخل هذه البيئة.

## ملاحظة النسخ
النسخ JSON تتضمن جدول الأحداث والإعدادات الأساسية فقط، ولا تتضمن ملفات صوت. مشاركة النسخة تتم كنص JSON، أما تصدير الملف فيحفظ ملفًا يمكن إرساله من مدير الملفات.
